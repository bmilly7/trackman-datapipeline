# trackman-datapipeline
A data pipeline to clean and create actionable insights using TrackMan's sensor data via my teams personal TrackMan device.  
Trackman has been elevating athletes of all levels for a decade now by creating advanced technology to provide athletes, primarily in golf and baseball, with precise, real-time data on performance metrics like club/pitch speed, spin rate, launch angle, and trajectory. These metrics break sports down to a true science allowing athletes to home in on very specifics aspects of their games. As a collegiate golfer and former collegiate baseball player, I spend a lot of time using a trackman device and have hundreds of data points on my personal golf swing. I love breaking down the numbers and improving every aspect of my golf game. As a computer science major, I am motivated to use the skills I have learned studying CS to build something useful relating to the sport I love. 
The proposed system is an end-to-end data pipeline designed to transform raw TrackMan session exports into structured, analysis-ready performance data. The pipeline begins by ingesting CSV files generated by TrackMan and storing them in a raw data layer to preserve the original source data. From there, the system performs validation and cleaning processes, including schema enforcement, type standardization, and configurable filtering rules to remove warm-up shots, mishits, and statistical outliers.
